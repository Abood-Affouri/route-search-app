# West Bank Route Search

A simple web application built with Python and Streamlit for the Fundamentals of Artificial Intelligence course. It finds routes between cities using BFS, DFS, UCS, Greedy Best-First Search, and A*.

The app displays the path, total cost in kilometers, and number of steps. It also supports comparing all algorithms and uploading a custom JSON map.

## How to Run

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```
